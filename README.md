An Android application designed to simplify beverage and consumable stock management for bars and hospitality businesses.

- Low-stock monitoring.

- JSON backup and data restoration.
- Local persistence using Room.
- MVVM architecture with Repository and DAO layers.
- Database migrations and technical documentation.
